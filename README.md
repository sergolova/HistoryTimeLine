# Историческая хроника (HistoryTimeLine)

Веб-приложение для визуализации исторических событий на интерактивном таймлайне. Позволяет создавать, редактировать и фильтровать исторические события, группировать их по категориям и тегам, а также просматривать связанные статьи из Википедии.

## Возможности

- **Интерактивный таймлайн** — события отображаются на временной шкале с возможностью масштабирования и прокрутки
- **Группы событий** — категоризация событий (войны, государства, люди, культура и т.д.) с цветовой маркировкой
- **Теги** — гибкая система тегов с фильтрацией по включению/исключению
- **Поиск** — мгновенный поиск по названию, описанию и тегам с подсветкой результатов
- **Связанные события** — создание связей между событиями для навигации
- **Википедия-интеграция** — автоматический поиск связанной статьи и изображения
- **Импорт/экспорт** — сохранение и загрузка данных в формате JSON
- **Локальное хранилище** — все данные автоматически сохраняются в браузере

## Запуск

### Простой способ

Откройте файл `index.html` в современном браузере (Chrome, Firefox, Edge).

### Через локальный сервер (рекомендуется)

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

Затем откройте `http://localhost:8000` в браузере.

## Использование

### Добавление события

1. Нажмите кнопку **«Событие»** на панели инструментов
2. Заполните обязательные поля: ID, название, группу и дату начала
3. При необходимости укажите дату конца (для интервалов), описание, теги и связанные события
4. Нажмите **«Сохранить»**

### Фильтрация

- **Группы** — используйте чекбоксы на левой панели для отображения/скрытия групп
- **Теги** — кликните по тегу для включения в фильтр, используйте кнопку «—» для исключения
- **Поиск** — введите запрос в поле поиска, при необходимости включите подсветку результатов

### Импорт/экспорт

- **Экспорт** — меню «Данные» → «Сохранить...» — скачает JSON-файл с текущим состоянием
- **Импорт из файла** — меню «Данные» → «Загрузить...» — загрузит ранее сохранённый JSON
- **Импорт из буфера** — кнопка «Из буфера» — вставьте JSON напрямую в текстовое поле

## Технологии

- **Vanilla JavaScript** — без фреймворков и сборщиков
- **vis-timeline 8.5.1** — библиотека для визуализации таймлайнов
- **localStorage** — хранение данных в браузере
- **Wikipedia API** — получение статей и изображений
- **Google Fonts** — шрифты Cinzel и Philosopher

## Формат данных

```json
{
  "groups": [
    { "id": "wars", "content": "Войны и конфликты" }
  ],
  "items": [
    {
      "id": "event-id",
      "group": "wars",
      "content": "Название события",
      "start": "1914",
      "end": "1918",
      "type": "range",
      "tags": ["война", "XX век"],
      "description": "Описание события",
      "related": ["another-event-id"]
    }
  ]
}
```
